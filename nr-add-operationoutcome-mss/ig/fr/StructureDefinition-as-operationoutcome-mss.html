Profil de ressource: AS OperationOutcome MSS

URL officielle: https://interop.esante.gouv.fr/ig/fhir/annuaire/StructureDefinition/as-operationoutcome-mss Version: 1.2.0-snapshot-3
Draft à date du 2026-11-12 Nom computable: AsOperationOutcomeMssProfile

Profil d'OperationOutcome retourné par l'API de gestion des BAL MSSanté (création, modification, suppression via PATCH avec une ressource Parameters) lorsqu'une requête est refusée. Il impose, pour chaque anomalie, une sévérité, un code de type d'anomalie et un message lisible en français.

Utilisations:

  • Exemples pour ce/t/te Profil: OperationOutcome/AsOperationOutcomeMssAttachmentAlreadyExistsExample, OperationOutcome/AsOperationOutcomeMssAttachmentNotFoundExample, OperationOutcome/AsOperationOutcomeMssBadEmailFormatExample, OperationOutcome/AsOperationOutcomeMssMssAccountNotFoundExample... , OperationOutcome/AsOperationOutcomeMssResourceTypeMismatchExample, OperationOutcome/AsOperationOutcomeMssTooLongExample, OperationOutcome/AsOperationOutcomeMssTypeBalImmutableExample and OperationOutcome/AsOperationOutcomeMssTypeBalRequiredExample

Vous pouvez également vérifier les usages dans le FHIR IG Statistics
